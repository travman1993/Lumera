# Lumera
Streaming and creator discovery platform for filmmakers, production crews, and visual creators.

The platform focuses on:
- Film and video streaming
- Creator portfolios
- Contributor credit systems
- Production metadata
- Industry discovery
- Festival and networking features

## Planned Features

- Creator profiles
- Film uploads
- Streaming infrastructure
- Contributor tagging 
- Comments and likes
- Analytics dashboard
- Festival discovery 
- Sports cinematics and documentary categories

## Tech Stack

### Frontend
- React
- Tailwind CSS
- Framer Motion

### Backend
- Python (FastAPI)
- PostgreSQL

### Media Infrastructure
- FFmpeg
- HLS Streaming
- Cloud Storage

## Status 

Currently in early development and architecture planning.
